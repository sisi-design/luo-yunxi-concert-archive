# 라운희 콘서트 곡 아카이브

라운희(罗云熙)의 2024 《此刻 X 以光》과 2026 난징·광저우 콘서트 세트리스트, 확인된 YouTube 영상을 정리한 정적 웹페이지입니다.

## 구성

- 2024 《此刻 X 以光》 실제 공연 순서 21곡, 난징 33곡, 광저우 31곡
- 《此刻 X 以光》 전체 공연 영상(2:20:08)과 3분 이상 개별 직캠 16개 연결
- 곡명 검색 및 공연 탭 전환
- 확인된 YouTube 영상을 콘서트 직캠·라운희 공연·공식 OST·원곡 영상으로 구분
- 3분 이상 난징 풀버전은 `@luoyunxi-fans` 채널 영상을 우선 연결
- 곡별 한자 한국식 발음·중국어 병음·한글 발음 표기
- 곡의 앨범/OST/원곡 정보와 저작권을 침해하지 않는 가사 주제 요약
- 데스크톱·모바일 반응형 레이아웃

별도의 빌드 과정 없이 `index.html`을 바로 열거나 정적 웹 서버에서 제공하면 됩니다.
