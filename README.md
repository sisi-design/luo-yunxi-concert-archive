## 구성

- 난징 33곡, 광저우 변경·신규 5곡
- 곡명 검색 및 공연 탭 전환
- 확인된 YouTube 영상 22개 연결(라운희 공연·공식 OST·원곡 영상 구분)
- 38곡 전체 한자 한국음·중국어 병음·한글 발음 표기
- 곡의 앨범/OST/원곡 정보와 저작권을 침해하지 않는 가사 주제 요약
- 데스크톱·모바일 반응형 레이아웃
